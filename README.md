# escala-plantao-lab-biologia

## Descrição do Problema
Sistema para gerar a escala de plantão dos técnicos do laboratório de biologia, considerando a ordem de entrada e a regra de equilíbrio de carga de trabalho.

## Requisitos
- Receber a lista de técnicos em ordem alfabética
- Distribuir os 12 turnos da semana entre os técnicos
- Garantir que nenhum técnico fique com mais de 4 turnos

## Exemplo de Uso
Entrada: ["Ana", "Bruno", "Carla"]

Saída:
Ana: 4 turnos
Bruno: 4 turnos
Carla: 4 turnos
